# TabMgmt
Overview
TabMgmt is a comprehensive tool designed to streamline the management of various key components such as connections, permissions, subscriptions, and user-related activities. Built in Python, this application provides an intuitive user interface along with efficient backend services to ensure smooth functionalities.

Features
Connection Management: Manage and audit server connections effectively.
Reports and Audits: Generate insightful reports and perform permission audits for enhanced security.
Subscription Management: Handle subscriptions efficiently with easy-to-use interfaces.
User Management: Control user permissions and manage profiles conveniently.
Server Overview: Access detailed server overviews to monitor performance and settings.
Workbook Refreshing: Automate and manage workbook refresh processes.
Settings Customization: Tailor settings to meet specific needs and optimize operations.
Project Structure
app.py: The main application script.
config.py: Configuration settings that define the tool's behavior.
main.py: Core execution script that coordinates various components.
pages/: Contains scripts specific to individual management pages like connection management, user management, reports, etc.
services/: Backend service scripts, including services related to platforms like Tableau.
ui/: User interface components, including widgets and dialogs for seamless interaction.
Installation
Clone the repository:

bash
git clone https://github.com/splnut/TabMgmt.git
Navigate to the directory:

bash
cd TabMgmt
Install required dependencies:

bash
pip install -r requirements.txt
Usage
Run the main application:

bash
python app.py
